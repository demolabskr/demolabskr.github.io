01 / Vibe Coding

기획에서 운영까지,
직접 만드는 바이브 코딩

무엇을 만들지 판단하고, AI와 함께 구현하고, 사용자의 반응으로 개선합니다. 교육공학자의 분석·설계·평가 역량으로 서비스의 전 과정을 연결합니다.

01 / Define

문제를 정의합니다

누가 어떤 상황에서 어려움을 겪는지 살피고, 해결할 문제와 서비스의 목표를 정합니다.

문제 분석 · 사용자 이해 · 범위 설정

02 / Design

사용할 구조를 설계합니다

비즈니스 로직과 사용자 동선을 정리하고, 화면과 데이터가 어떻게 연결될지 설계합니다.

서비스 기획 · UX · 데이터 구조

03 / Build

AI와 함께 구현합니다

AI 에이전트와 코드를 작성하고, 실제 사용 흐름을 테스트합니다. 기능을 확인한 뒤 서비스로 배포합니다.

바이브 코딩 · 테스트 · 배포

04 / Operate

운영하며 개선합니다

사용 기록과 피드백을 살펴 기능을 개선하고, 반복 업무를 자동화하며 운영 방식을 다듬습니다.

사용자 피드백 · 자동화 · 지속 개선

교육공학의 설계 역량 + IT·서비스 경험 + AI를 활용한 구현
기획자가 직접 구현하고 운영하면서 판단을 검증하는 방식입니다.
